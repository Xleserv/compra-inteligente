# Compra Inteligente

**Não é o menor preço. É o custo real.**

Metodologia de busca de compras: preço verificado, cupons e pontos na mesma conta, em lojas confiáveis.
Este repositório guarda **somente as imagens** usadas nos e-mails (é público para que as imagens carreguem). Nenhum dado pessoal fica aqui.

## Estrutura

```
marca/                      identidade do Compra Inteligente (capa, logo)
lojas/                      logos das lojas, usados em todas as categorias
categorias/<categoria>/produtos/   fotos dos produtos de cada categoria
```

## Regras para nomes de arquivo

- tudo minúsculo, sem acento, sem espaço, palavras separadas por hífen
- exemplos: `lojas/sephora.png`, `categorias/perfumes/produtos/dior-sauvage-edp.jpg`
- prefira `.jpg` para fotos e `.png` para logos, com até ~300 KB
